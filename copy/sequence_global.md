# Global sequence: outbound and lead-gen agencies (US, UK, EU and rest of world)

Same structure, timing and offer as the India sequence. Framing is client onboarding speed and keeping
deliverability healthy across many client domains, without the time-zone and currency angle. Merge tags as in
`sequence_india.md`.

Offer and single CTA everywhere: a free audit of one client's sending domains, shown on a 15 minute call.

## Signal line: Clay prompt

`{{signal_line}}` is a placeholder. It is filled by a Clay AI research column (Claygent) run on the people
table, using the prompt below. Then add a formula column `signal_line_lc` that lower-cases the first letter,
for the LinkedIn note where the line follows "Hi {{first_name}},". Export both with the list. If Clay returns
nothing for a row, map `{{signal_line}}` to the workflow's `first_line` column instead (generated by
`run.py build` from the company description, DNS and growth data), so no row goes out without an opener.

Prompt (global version):

```
You are researching {{Full Name}}, {{Title}} at the agency {{Company Name}} ({{Domain}}),
an outbound or lead generation agency that runs campaigns for clients.

Find ONE recent, specific, verifiable signal, checking in this order and stopping at the first hit:
1. Hiring: open roles for SDRs, BDRs, appointment setters, cold email or campaign managers,
   lead generation executives, deliverability or GTM engineers. Check {{Domain}}/careers,
   their LinkedIn Jobs page, Wellfound and Indeed.
2. New market: a new office, entity or launch in another country in the last 90 days.
3. A recent LinkedIn post by {{Full Name}} about cold email, deliverability, domains, mailboxes,
   warmup, or running outbound for clients.
4. A new case study, Clutch or GoodFirms review, or named client added to {{Domain}}.
5. Sending tools they name on {{Domain}} (Smartlead, Instantly, lemlist, HeyReach, Apollo and similar).

signal_type is one of: hiring, expansion, linkedin_post, case_study, tool_stack.
Good examples:
"Saw Bleed AI is hiring a campaign manager, so I guess client volume is up."
"Noticed LeadHQ just opened a London office."
"Your post on Google tightening bulk sender rules was a useful read."

Rules:
- Use only facts you can see on a page you opened. Put that page in signal_source_url.
- Only use something from the last 90 days (posts: last 30 days). If nothing qualifies, return empty fields.
- Write signal_line as one sentence, 25 words or fewer, in plain spoken English, starting with what you saw
  (for example "Saw..." or "Noticed..."). Name the company, not the person.
- No em dashes, no en dashes, no exclamation marks, no quotation marks, no flattery words like "amazing".
- Never mention InboxKit, never pitch, never guess numbers.
Return JSON only: {"signal_line": "...", "signal_type": "...", "signal_source_url": "..."}
```
